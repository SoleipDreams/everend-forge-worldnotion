<h1 align="center">Everend WorldNotion</h1>
<p align="center">Aplicación de escritorio gratuita y open source para crear mundos en carpetas Markdown locales.</p>

<p align="center"><a href="README.md">English</a> · <a href="https://github.com/SoleipDreams/everend-forge-worldnotion/releases/latest">Descargar gratis</a> · <a href="https://website-everend-forge.pages.dev/">Conocer la Suite integrada</a></p>

## Qué puedes hacer

- Abrir una carpeta local como universo.
- Navegar notas Markdown, metadatos YAML, wikilinks y backlinks.
- Buscar entidades, revisar enlaces rotos y editar notas sin moverlas a la nube.
- Compartir la misma bóveda con PathBranching y Compendium.

## Desarrollo

~~~sh
npm install
npm run build
npm run tauri dev
~~~

Consulta [los Releases](https://github.com/SoleipDreams/everend-forge-worldnotion/releases/latest) para obtener instaladores y la [guía de producto](docs/PRODUCT_DIRECTION.md) para ver cómo se conecta con las otras herramientas.
